# ArthurTech — Черновик книги квестов (FTB Quests)

Baseline: git `6e48f37`, GTCEu 7.5.1. Все ID сверены с живым кодом (`common.*`).
Раскладку (x/y, линии связей) генерит редактор в игре — здесь только **содержание**: главы, задачи, награды, тексты, зависимости.

**Как читать задачи:**
- `item skufaddon:<id>` — наш предмет (точный ID из `SkufItems`).
- `tag <prefix> skufaddon:<material>` — материал GTCEu с тег-префиксом (`dust`, `ingot`, `plate`, `gem`, fluid и т.д.). В редакторе FTB это Item/Fluid task по тегу `forge:<prefix>s/<material>` (GTCEu сам регистрирует теги).
- `machine skufaddon:<tier>_<base>` — построить/иметь машину. Тиры: `lv_`, `mv_`, `hv_` (машины зарегистрированы LV→UHV, но рецепты пока до HV).
- `multiblock skufaddon:<id>` — мультиблок (`skufizator`, `sauna_egora`, `razbor_geympleya`).

**Легенда статуса:**
- ✅ ГОТОВО — предмет/машина есть в коде и craftable.
- ⚠️ ПРОВЕРИТЬ — есть в коде, но цепочка получения под вопросом (орфан/софт-лок).
- 🔲 НЕТ В КОДЕ — предмет/механика пока не реализованы (эндгейм) → квест держим в черновике, включаем после Фазы 3.

Реальные предметы (`skufaddon:`): dodik_circuit_1/2/3, pravilnaya_vesh, cnc_bit, cnc_cutter, capacitor, burnt_capacitor, burnt_cable_debris, charred_developer_circuit, myposhko_script, egor_core, correct_matter_microcapsule, antizoomer_core, correct_developer_schematic, normis_singularity, absolute_pohuit, arturian_mainframe, demo.
Материалы: jizhnyak, normie_dust, skufit, pokhuit, honest_steel, correct_matter, ural_isotope, sweat, hidden_sweat, diluted_sweat, condensed_sweat, technical_tears, dense_jizhnyak, zhizhnyak_loss, slag_ignore, chelyabinsk_shale, crystallized_dodik_sweat, stabilized_vibe, padik_noble_gas, ugar_gas, puff_smoke, warm_vibe_steam, coolant_of_denial.

## Заметки для реализации в редакторе
1. Главы 1–4 (Q1.1 … Q4.5) можно вбивать **прямо сейчас** — все предметы/машины существуют и craftable.
2. Глава 5: квесты Q5.1–Q5.4 (компоненты) тоже готовы; Q5.5–Q5.7 (финал) — держать скрытыми/заблокированными, пока не сделана Фаза 3.
3. Тег-задачи (`dust/ingot/plate/...`): в редакторе FTB выбирай Item task и жми на предмет из JEI — тег подхватится сам.
4. Тильтовые/энтропийные квесты (Q3.2, Q3.4) — через Observation/Advancement task или Check task; если нет готового advancement, временно сделать Item-наградой за ручное действие.
5. Флейвор-тексты взяты из философского дока (30-квестовый questbook) и адаптированы под реальные предметы. Полный набор оригинальных текстов — `.temp/Философия Артура в GregTech (1).txt`.
