# ArthurTech — FTB Quests datapack

Questbook for the SkufAddon / ArthurTech modpack (FTB Quests, Minecraft 1.20.1 Forge).

- **Source of truth:** generated by [`scripts/generate_ftbquests.py`](../scripts/generate_ftbquests.py).
  Do not hand-edit the `.snbt` under `config/` — re-run the generator instead (IDs are deterministic).
- **Content:** 42 quests across 6 chapters — a single connected progression spine from
  «Грязный двор» (Steam) → LV → MV → HV → Сауна/Челябинск → «Абсолютный Похуизм» (endgame).
- Every task references a **real** registered id (verified against the live game registry):
  38 item tasks, 4 fluid tasks, 3 checkmark tasks.
- Material items use GTCEu's `{material}_{prefix}` ids (e.g. `skufaddon:skufit_ingot`,
  `skufaddon:correct_matter_gem`); material tags use `forge:<prefix>s/<material>` via `itemfilters:tag`.

## Install / test

Copy into the dev run dir (or a modpack instance) and clear the FTB cache:

```
cp -r quests/config/ftbquests/quests/* run/config/ftbquests/quests/
rm -rf run/local/ftbquests
```

Then launch (`run.bat` → [1] runClient). In-game: pencil/edit icon or `/ftbquests editing_mode`.

## Known-incomplete: 3 locked finale quests

The endgame chapter ends with **3 checkmark-only quests that are intentionally locked** because the
underlying content is **not implemented in code yet** (tracked in Linear SKU-40 / SKU-41 / SKU-43 / SKU-44):

| Quest | Blocked on |
|---|---|
| Сингулярность «Деревенский Покой» | item `derevenskiy_pokoy_singularity` + recipe (SKU-40) |
| Врата ПГТ | multiblock `pgt_gate` (SKU-41) |
| Деревенский Покой (финал) | ПГТ biome/dimension + entry advancement (SKU-43/44) |

Once those items/multiblocks exist, swap the checkmark tasks for real `item`/advancement tasks in the
generator and regenerate.
